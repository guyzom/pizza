# חברים על ארבע — הרפתקת פיצה

משחק ריצה תלת־ממדי בעברית, עם ארבעה כלבים חברים: ביסקו, פלפל, טופי וקוקו. המסע עובר בפארק, בפיצרייה ובגגות השכונה, בשלושה עולמות ותשעה שלבים. הדמויות בעלות ארבע רגליים, אוזניים וזנב, ונבנות מצורות תלת־ממדיות; התפריטים משלבים דיוקנאות SVG. המשחק כולל שליטה במגע ובמקלדת, שמירה מקומית והפעלה ללא רשת לאחר התקנה.

## שליטה

הדמות רצה אוטומטית. גרירה הצדה מעבירה בין שלושה מסלולים והקשה קצרה מקפיצה. בתחתית המסך יש גם כפתורי שמאלה, ימינה, כוח על וקפיצה. איסוף פיצות טוען את כוח העל; כשהכפתור פעיל ניתן להפעילו. התנגשות מפחיתה אנרגיה והמסע ממשיך. השלבים האחרונים בכל עולם כוללים בוס.

במחשב: חצים ימינה ושמאלה לתנועה, רווח לקפיצה ו־Escape להפסקה. רווח על כפתור ממוקד מפעיל את הכפתור. חלון ההסבר מופיע לפני השלב הראשון וזמין גם במסך הבית.

## הגדרות

ההגדרות זמינות ממסך הבית, מהמפה ומתוך ההפסקה:

- **קצב נינוח:** מופעל כברירת מחדל ומאט את הריצה. השינוי חל מהשלב הבא.
- **פחות תנועה:** מסיר רעידות מצלמה ואנימציות קישוטיות. תנועת המשחק נמשכת; העדפת הפחתת תנועה במערכת ההפעלה נתמכת גם היא.
- **ללא צלילים:** השתקת מוזיקה ואפקטים.
- **איכות תמונה:** אוטומטי, חיסכון או גבוהה. מצב חיסכון מצמצם רזולוציית רינדור, צללים ואפקטים.

חזרה מההגדרות בזמן הפסקה משאירה את המשחק מושהה.

## שמירה והפעלה ללא רשת

כוכבים, מדבקות, בחירת דמות והגדרות נשמרים בדפדפן המקומי, עם עותק שחזור נוסף באותו אחסון. חזרה על שלב אינה מורידה את ציון השיא. נתוני שמירה פגומים מנורמלים או משוחזרים מהעותק המקומי; כשל שמירה מוצג בלי לחסום משחק.

אין חשבונות, רכישות, פרסומות או קוד מעקב באפליקציה. אין שמירת מיקום באמצע שלב או סנכרון בין מכשירים. מחיקת נתוני האתר, אובדן המכשיר או פינוי אחסון בדפדפן עלולים למחוק את שני העותקים.

טעינה ראשונה דורשת חיבור. לאחר התקנת המטמון ב־HTTPS או ב־localhost מופיעה הודעת מוכנות להפעלה ללא רשת. באייפד: תפריט השיתוף ב־Safari ← הוספה למסך הבית. פתיחת קובץ HTML ישירות אינה מתקינה את המטמון. עדכון ממתין לסגירת כל חלונות המשחק ומופעל לאחר פתיחה מחדש; אין למחוק נתוני אתר לצורך עדכון.

## הרצה מקומית

מהתיקייה הראשית של הריפו:

```sh
python3 -m http.server 8000 --directory game
```

כתובת: <http://localhost:8000/>. נדרש דפדפן עם JavaScript ו־WebGL. [QA.md](../QA.md) מפרט בדיקות אוטומטיות ומגבלות, כולל הצורך בבדיקת Safari ומצב טיסה על מכשיר פיזי.
